# 📷 写真かるくする

スマホの写真をまとめて選ぶだけで、**端末の中だけで**（外部サーバーに一切送信せず）自動で軽量化し、社用PCの受信容量（合計10MB）に収まる状態にして、共有シートから直接Gmailに渡せるツールです。

## 使い方（アプリを使う人向け）

1. 以下のURLをスマホのブラウザ（Safari / Chrome）で開く
   👉 **https://miruhana.github.io/sumaho-shayoPC-shashin-sofu/**
2. 「写真を選ぶ」をタップし、送りたい写真をまとめて選択する
3. 自動で軽量化される（HEIC→JPEG変換・圧縮を自動実行）
4. 「共有してGmailに渡す」をタップし、共有シートで「Gmail」を選ぶ
5. 添付された状態で新規メールが開くので、宛先を入力して送信する

### ホーム画面に追加しておくと便利です
Safariでこのページを開いた状態で、共有ボタン→「ホーム画面に追加」を選ぶと、アプリのようにアイコンから起動できるようになります（インストール不要）。

## このツールの特徴

- 写真・データは一切サーバーに送信されません。すべての処理はスマホのブラウザ内だけで完結します。
- 選んだ写真「全体の合計」が社用PCの受信上限（10MB）に収まるよう、自動で圧縮の強さを配分します。
- HEIC形式の写真は自動でJPEGに変換されます。

## 開発者向け

- ビルド不要の単一HTMLファイル（[index.html](index.html)）のみで構成された静的Webアプリです。
- 詳しい仕様は [要件定義書_スマホデータ軽量化アプリ.md](要件定義書_スマホデータ軽量化アプリ.md) を参照してください。
- GitHub Pagesで配信しているため、`index.html` を更新して `master` ブランチにpushすれば自動的に反映されます。
